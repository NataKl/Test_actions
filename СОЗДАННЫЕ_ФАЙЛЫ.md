## 📦 GitHub Actions Workflows (2 файла)

### ⭐ `.github/workflows/deploy.yml` - ОСНОВНОЙ WORKFLOW
**Рекомендуется для использования**

Что делает:
- 🏗️ Собирает Docker образ из вашего Dockerfile
- 📤 Публикует образ в GitHub Container Registry (GHCR)
- 🔐 Подключается к серверу по SSH
- 🚀 Деплоит новую версию приложения
- ✅ Проверяет работоспособность через health endpoint

Триггеры:
- Push в ветку `main` или `master`
- Создание Git тега (`v*`)
- Ручной запуск через GitHub Actions UI

### 🚀 `.github/workflows/deploy-compose.yml` - ПРОДВИНУТЫЙ WORKFLOW
**Опциональный, для сложных проектов**

Что делает:
- То же самое, но использует Docker Compose
- Копирует `docker-compose.yml` на сервер
- Управляет контейнерами через docker-compose
- Подходит для multi-container приложений
